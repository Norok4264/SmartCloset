# 진행 상황

## 0단계: 설계와 기본 구조

- 완료: Android 단일 모듈 Gradle 구성, Kotlin/Compose Material 3 테마, 앱 진입점, 5개 하단 탭, Navigation Compose 경로, 한국어 준비 화면, 간단한 ViewModel 연결, 문서 구조
- 완료: 기능 범위, 관계형 데이터 모델, 이미지 저장 및 삭제·마이그레이션·AI 개인정보 원칙 설계
- 완료: 실제 Room v1 Clothing 저장소, 검색/종류/계절/색상 필터 Flow, 사진 중심 그리드와 상세/수정/삭제, 즐겨찾기, 세탁 안내
- 완료: 시스템 Photo Picker와 카메라 촬영, 내부 파일 복사·리사이즈·EXIF 회전 보정, 임시 파일 정리 및 DB 저장 실패 정리
- 완료(2단계): Room Flow 실제 등록 의류 기반 총계·종류 비율·계절/계절×종류 수량·즐겨찾기 통계, Preferences DataStore 목표 설정, 부족 안내, 순수 계산기와 단위 테스트 작성
- 완료(3단계 구현): Room v1→v2 보존 마이그레이션, 일자별 착용 기록/유일 제약, 상세 화면 기록 CRUD, DB COUNT/MAX 집계, 트랜잭션 일괄 기록 API, 기간별·구매일 분석, DataStore 분석 기준, 날짜 주입형 분석 계산기 및 단위·Android 통합 테스트
- 미완료(후속 단계): Outfit/TryOn 테이블, 코디·AI
- 검증: 빌드 및 테스트 명령을 실행하려 했으나 현재 실행 환경에서 gradle 명령을 찾지 못해 빌드/테스트 실행 불가. Android SDK/Java 경로도 확인되지 않아 에뮬레이터·DB 마이그레이션·기기 시나리오 미검증. Gradle Wrapper 미포함.

## 4단계: 날씨·코디 추천 및 저장

- 완료(구현): Room v2→v3 비파괴 마이그레이션, saved Outfit 테이블과 실제 Clothing 외래 키, 구성 의류 삭제 시 코디 cascade 정리
- 완료(구현): 룰 기반 상의·하의 코디 및 선택 아우터, 고정 난수 지원, 이전 조합 회피, 필요한 의류가 없는 상태 안내, 실제 옷 상세 이동
- 완료(구현): 저장 코디 이름·즐겨찾기, 중복 조합 안내, 코디 즐겨찾기/저장 목록, 코디 상세 화면
- 완료(구현): 코디 착용을 3단계 트랜잭션 일괄 기록 API로 연결. 추천·저장만으로는 기록하지 않음
- 완료(구현): 사용자가 직접 선택하는 지역 검색, Open-Meteo 날씨, 실제 시각이 표시된 캐시·실패·지역 미설정·수동 모드, DataStore 보존
- 완료(구현): WorkManager 데일리 코디 알림 설정과 Android 13+ 알림 권한 처리, 정시 실행 보장 안 함을 안내
- 5단계 상태는 아래 2026-11-05 완료 현황을 참조한다.
- 테스트 코드: 순수 코디 규칙 단위 테스트와 v1→v3 마이그레이션/저장 코디 중복·cascade Android 통합 테스트 추가
- 검증: `gradle :android:app:testDebugUnitTest :android:app:assembleDebug` 실행을 시도했으나 환경에 `gradle` 실행 파일이 없어 빌드/테스트를 시작하지 못함. Android Studio/에뮬레이터 실행도 미검증. 테스트 성공으로 기록하지 않음.


## 5단계 완료 현황 (2026-11-05)

- 코드 작성: Android Try-On 화면·서버 API 연결, 전신 이미지 전용 앱 저장, 실제 Room 상의 선택, 동의/제공사 설정 상태, 결과 조회·파일 내보내기·삭제, 작업 재실행 후 복원.
- 코드 작성: FastAPI 계약, SQLite 작업/세션 상태, 사용자 소유 범위, UUID 멱등성 제약, 세션별 일일 한도, 이미지 크기/형식/메타데이터 처리, 24시간 로컬 정리, Android Keystore 세션 토큰 보관.
- 제공사 문서 확인: Google Cloud Virtual Try-On API와 가격/접근/데이터 정책을 `docs/AI_PROVIDER.md`에 기록. 해당 모델은 폐기 상태이며 2027-03-15 지원 종료 예정이라 실서비스 장기 사용은 대체 API 재평가가 필요하다.
- 테스트용 Mock은 개발 환경의 테스트 안내 카드만 반환한다. 실제 AI 이미지처럼 표현하지 않는다. 기본 서버 설정은 disabled.
- 정적 Python compileall: 성공. 백엔드 pytest는 시스템 Python SSL DLL 오류로 시작하지 못했고, 별도 SQLite 실행 확인도 `_sqlite3` DLL 오류로 실행되지 않았다. Android 빌드/단위 테스트: Gradle 실행 파일 및 Wrapper 부재로 미실행.
- GCP 인증, API 호출, 실제 결과 품질/비용, 에뮬레이터·실기기 동작은 검증하지 않았다. 현재 상태는 코드 구현이며 AI 실연동 완료가 아니다.
